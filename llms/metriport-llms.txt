# Metriport

## Docs

- [Quickstart](https://docs.metriport.com/medical-api/getting-started/quickstart.md): Follow this guide to start exchanging comprehensive patient medical data.
- [API Keys](https://docs.metriport.com/medical-api/getting-started/api-keys.md): Learn more about API key security best practices.
- [Implementing Webhooks](https://docs.metriport.com/medical-api/getting-started/webhooks.md): Receive data as soon as it becomes available.
- [Sandbox Mode](https://docs.metriport.com/medical-api/getting-started/sandbox.md): Build your application using example clinical data
- [Message Delivery](https://docs.metriport.com/medical-api/getting-started/message-delivery.md): Exchange clinical data directly with another practitioner.
- [Individual Access (IAS)](https://docs.metriport.com/medical-api/getting-started/ias.md): Let your users pull their own medical records into your application.
- [Embedding Metriport](https://docs.metriport.com/medical-api/getting-started/embedding.md): Embed the Metriport app directly into your application.
- [Create Facility](https://docs.metriport.com/medical-api/api-reference/facility/create-facility.md): Creates a Facility in Metriport where your patients receive care.
- [Get Facility](https://docs.metriport.com/medical-api/api-reference/facility/get-facility.md): Gets a Facility.
- [Update Facility](https://docs.metriport.com/medical-api/api-reference/facility/update-facility.md): Updates a Facility in Metriport where your patients receive care.
- [List Facilities](https://docs.metriport.com/medical-api/api-reference/facility/list-facilities.md): Lists all of your Facilities.
- [Delete Facility](https://docs.metriport.com/medical-api/api-reference/facility/delete-facility.md): Deletes a Facility. Returns 400 if there are patients associated with the Facility.
- [Create Patient](https://docs.metriport.com/medical-api/api-reference/patient/create-patient.md): Creates a Patient in Metriport for the specified Facility where the patient is receiving care.
- [Get Patient](https://docs.metriport.com/medical-api/api-reference/patient/get-patient.md): Gets a Patient.
- [Get Patient by External ID](https://docs.metriport.com/medical-api/api-reference/patient/get-patient-external-id.md): Get a Patient based on External Identifier.
- [Update Patient](https://docs.metriport.com/medical-api/api-reference/patient/update-patient.md): Updates the specified Patient.
- [Match Patient](https://docs.metriport.com/medical-api/api-reference/patient/match-patient.md): Searches for a Patient previously created in Metriport, based on demographic data. Returns a 404 if the patient is not found.
- [Delete Patient](https://docs.metriport.com/medical-api/api-reference/patient/delete-patient.md): Removes the specified Patient.
- [List Patients](https://docs.metriport.com/medical-api/api-reference/patient/list-patients.md): Lists all Patients receiving care.
- [Sync Patient](https://docs.metriport.com/medical-api/api-reference/patient/create-patient-external-sync.md): Create a link between Metriport Patient and external system.
- [HIE Opt-Out](https://docs.metriport.com/medical-api/api-reference/patient/hie-opt-out.md): Update a patient's HIE (Health Information Exchange) opt-out status
- [Treatment Relationship](https://docs.metriport.com/medical-api/api-reference/patient/treatment-relationship.md): Update a patient's treatment relationship consent status
- [Bulk Patient Create](https://docs.metriport.com/medical-api/api-reference/patient/bulk-create-patient.md): Creates a batch of patients in Metriport and initiates Document Queries for all of them.
- [Add Patient to Cohorts](https://docs.metriport.com/medical-api/api-reference/patient/add-patient-to-cohorts.md): Adds a single patient to multiple cohorts at once. Returns all cohorts the  patient is associated with.
- [List Patient Cohorts](https://docs.metriport.com/medical-api/api-reference/patient/list-cohorts-for-patient.md): Returns a list of all cohorts the patient is a member of.
- [Get Patient Facilities](https://docs.metriport.com/medical-api/api-reference/patient/get-patient-facilities.md): Gets all facilities associated with a patient.
- [Set Patient Facilities](https://docs.metriport.com/medical-api/api-reference/patient/set-patient-facilities.md): Sets the facilities associated with a patient. This operation overrides any existing facility associations and replaces them with the provided list.
- [Create Embed Token](https://docs.metriport.com/medical-api/api-reference/token/create-embed-token.md): Generates an access token for embedding Metriport in your application.
- [Create AAL2 Challenge](https://docs.metriport.com/medical-api/api-reference/ias/create-aal2-challenge.md): Issues a fresh multifactor challenge for a verified user.
- [Create Identity Session](https://docs.metriport.com/medical-api/api-reference/ias/create-identity-session.md): Starts a hosted identity verification session for a user.
- [Get Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/get-cohort.md): Returns cohort with additional details including the count of patients assigned to it.
- [Update Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/update-cohort.md): Updates the details of an existing cohort (name, description, color).
- [Delete Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/delete-cohort.md): Deletes a cohort if the cohort is empty.
- [List Cohorts](https://docs.metriport.com/medical-api/api-reference/cohort/list-cohorts.md): Lists all cohorts defined by your organization.
- [Add Patients to Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/add-patients-to-cohort.md): Bulk assign multiple patients to a cohort.
- [List Patients in Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/list-patients-in-cohort.md): Returns a paginated list of all patients that are members of the specified cohort.
- [Remove Patients from Cohort](https://docs.metriport.com/medical-api/api-reference/cohort/remove-patients-from-cohort.md): Bulk remove patients from a cohort.
- [Send Message](https://docs.metriport.com/medical-api/api-reference/message/send-message.md): Send a message to another practitioner
- [List Messages](https://docs.metriport.com/medical-api/api-reference/message/list-messages.md): List all inbound and outbound messages.
- [Get Message Status](https://docs.metriport.com/medical-api/api-reference/message/get-message-status.md): Get the status of a message sent previously.
- [List Network Entries](https://docs.metriport.com/medical-api/api-reference/network/list-network-entries.md): List HIE directory entries that Metriport has access to.
- [Start Network Query](https://docs.metriport.com/medical-api/api-reference/network/start-network-query.md): Triggers a network query for the specified patient across all available health data networks.

- [Get Medical Record Summary Status](https://docs.metriport.com/medical-api/api-reference/fhir/get-medical-record-summary-status.md): Check if a Medical Record Summary for a patient already exists, and when it was generated.

- [PractitionerRole](https://docs.metriport.com/medical-api/fhir/resources/practitionerrole.md): A specific set of Roles/Locations/specialties/services that a practitioner may perform at an organization for a period of time.
- [Procedure](https://docs.metriport.com/medical-api/fhir/resources/procedure.md): An action that is or was performed on or for a patient. This can be a physical intervention like an operation, or less invasive like long term services, counseling, or hypnotherapy.
